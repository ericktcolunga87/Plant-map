First step: calibrate

This app needs 2–3 reference points to line GPS up with your map. Go to two different doorways (or step just outside) at opposite ends of the building — GPS is strongest there, and outdoor points position you correctly indoors too. At each one: tap your exact spot on the map, hold still ~30 seconds, save. A third point lets the app check its own accuracy.

Location blocked by the phone?

If the site never even asked, the block is in phone settings, not this app.

iPhone:

  1. Settings → Privacy & Security → Location Services: ON
  2. Same screen → Safari Websites → While Using the App, Precise ON
  3. In Safari on this page: aA button → Website Settings → Location → Allow
  4. Home-screen icon acting up? Test in plain Safari first, then re-add the icon.

Android:

  1. Chrome → ⋮ → Site settings for this site → Location → Allow
  2. Settings → Apps → Chrome → Permissions → Location: allow, Precise ON
